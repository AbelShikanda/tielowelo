# Goal

Build a tour & travel booking platform (skeleton first, then features) where users can browse tours, view itineraries/maps, check availability, book, and pay; admins manage tours/departures/bookings.

## Milestones
1. Skeleton (done): Laravel + Inertia + React + TS + Tailwind, build passing
2. Domain model: tours, departures, bookings, payments, reviews, destinations
3. Public pages: listing, detail, search/filter
4. Booking flow: availability, wizard, payment, confirmation
5. Admin (Filament): CRUD + reports
6. Polish: i18n, SEO, image optimization, tests
